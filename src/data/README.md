# Your content lives here

This folder holds all the **exercises** and **workouts** as plain data files you can
edit yourself — no app logic mixed in. Coming in Phase 1:

- `exercises.ts` — every drill (name, instructions, coaching cues, equipment…)
- `workouts.ts` — the ready-made sessions built from those exercises
- `plans.ts` — the multi-week training plans

Editing a value in these files changes what shows up in the app. You'll never need
to touch the code in `components/`, `screens/`, or `lib/` to add or tweak a drill.
